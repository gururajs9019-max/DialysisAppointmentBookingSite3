## 3. Automatically Calculate Weekly Dialysis Sessions

In the **Dialysis Prescription** form, there is an option to select the days on which the patient should attend dialysis.

For example:
- Monday
- Thursday
- Saturday

When the administrator selects dialysis days, the **Weekly Dialysis Session** field must automatically calculate the total number of selected days.

### Required behavior

Use a multi-select control or selectable checkboxes for the dialysis days.

The weekly session count must be calculated dynamically based on the selected days.

Examples:

| Selected dialysis days | Weekly dialysis sessions |
|---|---:|
| Monday | 1 |
| Monday, Thursday | 2 |
| Monday, Wednesday, Friday | 3 |
| Monday, Thursday, Saturday | 3 |
| Tuesday, Thursday, Saturday | 3 |
| All seven days | 7 |

### Implementation requirements

- Update Weekly Dialysis Session immediately whenever the selected days change.
- Do not require the user to click another button to calculate the count.
- Make Weekly Dialysis Session a read-only or automatically calculated field so users cannot accidentally enter an inconsistent number.
- If the user deselects a day, recalculate the count immediately.
- If no days are selected, display 0 or a suitable empty-state value until the user selects a day.
- Save both the selected days and the calculated weekly session count to the existing data model, using the project's existing conventions.
- When editing an existing dialysis prescription, restore the saved dialysis days and calculate the correct weekly count.
- Ensure the count remains correct after saving, refreshing the page, or reopening the prescription.

Use a single source of truth for the selected days and derive the weekly count from that selection. Do not maintain two independently editable values that can become inconsistent.

**Important:** Do not automatically create or modify dialysis appointments just because the selected prescription days change. This feature should update the prescription only unless the existing application explicitly provides a separate scheduling workflow.
